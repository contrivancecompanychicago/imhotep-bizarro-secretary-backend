# IMHOTEP Bizarros backend

IMHOTEP Bizarros is a prototype medical secretary backend and knowledge-base reference project. Use fictional data for development and research; this prototype is not a clinical decision-support or medical-coding system.

## Healthcare NLP experiment

The authenticated `POST /healthcare/analyze` endpoint can extract clinical entity mentions and relationships through Google Cloud Healthcare Natural Language. It does not generate medical codes or clinical recommendations. See [Healthcare NLP setup and scope](docs/healthcare-nlp.md) before configuring or using the integration.

Generated research outputs belong in the designated research results area. No study findings should be inferred from smoke demos or development-only examples. Keep raw query rankings, run metadata, and summaries together, and use fictional data only.
